AquaSense End-to-End System Pipeline

The system follows a strict non-leaking machine learning lifecycle from raw sensor and consumption logs to deployment and monitoring:

1. Data Ingestion

Raw data safely partitioned into data/raw/ without alteration or data mutation.

2. Data & Insights

Statistical distributions, missingness analysis, correlation matrices, and temporal patterns.

3. Model Pipelines

Linear regression, gradient descent, regularized models, tree ensembles, and clustering.

4. Serving & Drift

FastAPI inference endpoints, schema validation, and real input data drift tracking.
